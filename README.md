# План питания

План питания и тренировок на недели 8–23 (12 октября 2026 - 31 января 2027) в виде PWA для iPhone.

Сайт: https://avemepls95.github.io/nutrition-plan/

На iPhone: открыть сайт в Safari, «Поделиться» → «На экран „Домой“». Правки хранятся на телефоне, в localStorage приложения с главного экрана (отдельно от Safari).

## Структура

- `docs/`: сайт, публикуется через GitHub Pages (ветка `main`, папка `/docs`).
- `docs/plan.js`: данные плана, генерируются из PDF командой `python tools/extract_plan.py <путь к PDF>`.
- `tools/make_icons.py`: иконки приложения.

Service worker отдаёт файлы из кэша и в фоне проверяет свежие, поэтому новая версия сайта появляется на телефоне со следующего запуска. При каждой публикации меняйте версию `CACHE` в `docs/sw.js`, новый файл сайта добавляйте в `ASSETS`.
