# План питания

План питания и тренировок на недели 8–23 (12 октября 2026 - 31 января 2027) в виде PWA для iPhone.

Сайт: https://avemepls95.github.io/nutrition-plan/

На iPhone: открыть сайт в Safari, «Поделиться» → «На экран „Домой“». Правки хранятся на телефоне, в localStorage приложения с главного экрана (отдельно от Safari).

## Структура

- `docs/`: сайт, публикуется через GitHub Pages (ветка `main`, папка `/docs`).
- `docs/plan.js`: данные плана, генерируются из PDF командой `python tools/extract_plan.py <путь к PDF>`.
- `docs/foods.js`: калорийность продуктов по умолчанию, разбор состава на продукты с количеством и пересчёт состава под свою калорийность. Пишется руками.
- `tools/make_icons.py`: иконки приложения, шрифт для них лежит в `tools/fonts/`.

Калорийность продуктов в `docs/foods.js` подобрана так, чтобы сумма продуктов каждого блюда без кофе отличалась от ккал блюда в плане не больше чем на 1,5 ккал. Проверка: `node tools/check_foods.js`. Тесты разбора и пересчёта состава: `node --test`.

Настройки и правки на телефоне: `np.v1.edits` (правки приёмов пищи и добавленные приёмы пищи со временем, ккал в правках записаны по калорийности продуктов по умолчанию и без кофе), `np.v1.weights` (вес по неделям), `np.v1.kcal` (своя калорийность продуктов с днём, с которого она действует, и пометка удалённого своего продукта), `np.v1.dishes` (мои блюда), `np.v1.theme` (тема).

Service worker отдаёт файлы из кэша и в фоне проверяет свежие, поэтому новая версия сайта появляется на телефоне со следующего запуска. При каждой публикации меняйте версию `CACHE` в `docs/sw.js`, новый файл сайта добавляйте в `ASSETS`.
